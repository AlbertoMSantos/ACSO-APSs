# ACSO-APS01
Benchmark desenvolvido em Python para a APS01 de Arquitetura de Computadores e Sistemas Operacionais.

## Pré-requisitos
- Python 3 instalado. Verifique com:
  ```
  python --version
  ```
  Se não tiver, baixe em [python.org/downloads](https://www.python.org/downloads/).
- Não é necessário instalar nenhuma biblioteca extra.

## Como baixar
Clique em **"Code" → "Download ZIP"** nesta página e extraia o arquivo em uma pasta.

## Como rodar
```
cd caminho/da/pasta/extraida
python benchmark_desenvolvido.py
```
(No Mac/Linux, use `python3` se necessário.)

O programa executa as 5 tarefas 10 vezes e exibe no terminal o tempo de cada execução, além da média e do desvio padrão de cada tarefa ao final.
