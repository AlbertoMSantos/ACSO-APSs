# ACSO APSs & ATIVs

Repositório contendo Atividades Práticas Supervisionadas (APS) e Atividades (ATIV) da disciplina de **Arquitetura de Computadores e Sistemas Operacionais (ACSO)**.

## 📋 Estrutura do Repositório

O repositório está organizado da seguinte forma:

### **APS01** - Benchmark de Performance
Atividade prática sobre análise de performance e benchmarking em Python.

- **benchmark_desenvolvido.py** - Script Python que executa 5 tarefas 10 vezes cada, medindo e exibindo:
  - Tempo de execução individual de cada tarefa
  - Média de tempo de execução
  - Desvio padrão das medições

#### Como usar APS01:
1. **Pré-requisitos:**
   - Python 3 instalado. Verifique com: `python --version`
   - Nenhuma biblioteca extra necessária

2. **Executar:**
   ```bash
   cd APS01
   python benchmark_desenvolvido.py
   ```
   (No Mac/Linux, use `python3` se necessário)

---

### **APS02** - Programação em Assembly
Atividade prática sobre otimização e análise de cache em linguagem Assembly.

Contém 4 códigos Assembly diferentes demonstrando conceitos de cache:

1. **codigo1AcessoSequencial.asm** - Acesso sequencial à memória (bom para cache)
2. **codigo2AcessoComSalto.asm** - Acesso com saltos na memória (prejudicial para cache)
3. **codigo3ConflitoIntencional.asm** - Conflito de cache intencional
4. **codigo4Dimensionamento.asm** - Análise de dimensionamento de cache
